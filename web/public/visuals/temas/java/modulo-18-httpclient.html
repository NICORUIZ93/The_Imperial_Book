HttpClient: petición, timeout y respuesta

Qué debe entender: una llamada HTTP es I/O remota con éxito, error de negocio, error de servidor o timeout.

Lectura: La app envía request con timeout. El servicio puede responder 200, error, o no responder a tiempo. La animación resalta ida/vuelta y se apaga en reduced motion.

Movimiento reducido: si tu sistema pide reduced motion, la animación se desactiva y el diagrama queda estático.
