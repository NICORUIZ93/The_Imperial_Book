JVM por dentro: observar antes de tunear

Cada herramienta responde una pregunta distinta: GC logs para pausas, JFR para eventos del runtime, heap dump para retenciones, FFM para memoria nativa con dueño explícito.

Lectura: GC, JFR, referencias/heap dumps y FFM observan capas distintas. La salida útil no es “un número mágico”, sino evidencia en tu entorno con sus límites explícitos.
