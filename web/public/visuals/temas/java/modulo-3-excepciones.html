Excepciones: separar flujo normal, fallo recuperable y bug

El tipo, mensaje, causa y cierre de recursos cuentan la historia completa del error. No se traga; se maneja, se traduce o se propaga.

Lectura: el llamador decide con el tipo; el diagnóstico usa mensaje+causa+traza; try-with-resources evita fugas incluso si el cierre falla.
