Transacción: commit o rollback

Qué debe entender: un conjunto de cambios se confirma completo o se revierte completo.

Lectura: Si todas las operaciones son válidas se hace commit; si alguna falla, rollback restaura el estado previo. La animación solo resalta el flujo; el significado es legible en estático.

Movimiento reducido: si tu sistema pide reduced motion, la animación se desactiva y el diagrama queda estático.
