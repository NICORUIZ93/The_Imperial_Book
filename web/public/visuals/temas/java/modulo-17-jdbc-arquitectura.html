JDBC: capas entre Java y la base de datos

Qué debe entender: JDBC es una API Java; el driver traduce a protocolo de la BD; tu código no habla SQL nativo por sockets.

Lectura: La app usa la API JDBC; el driver específico traduce al protocolo de la BD. Cambiar de BD suele implicar driver/config/SQL dialect, no reescribir toda la app.
