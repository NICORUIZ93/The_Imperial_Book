La JVM como runtime: lo que el código fuente no muestra

Visibilidad de memoria, optimizaciones JIT, deserialización y ciclo de vida son comportamientos de runtime. Hay que diseñarlos y verificarlos, no asumirlos.

Lectura: el runtime puede cambiar timing, visibilidad y seguridad. Las decisiones se verifican con pruebas y evidencia, no con intuición.
