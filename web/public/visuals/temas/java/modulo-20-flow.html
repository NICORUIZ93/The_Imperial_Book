Flow API: backpressure por demanda

Qué debe entender: el Subscriber pide n elementos; el Publisher no debe inundarlo sin demanda.

Lectura: El suscriptor solicita cantidad (`request(n)`) y el publicador emite hasta esa demanda. Así se evita inundar al consumidor.

Movimiento reducido: si tu sistema pide reduced motion, la animación se desactiva y el diagrama queda estático.
