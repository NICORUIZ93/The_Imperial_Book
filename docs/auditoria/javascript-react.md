## 1. Veredicto ejecutivo

**Ninguno de los dos cursos cumple el objetivo de que «cualquier persona aprenda fácilmente». Veredicto: No.**

1. **Ningún ejercicio de los 156 temas tiene solución.** En los 30 archivos no hay ningún `<details>` ni ninguna sección «Solución». Los 23 temas de JavaScript y los 15 de React que `plantilla-mecanica.json` marca con `ejercicios_con_solucion: true` son falsos positivos: el detector encuentra la palabra «solución» en encabezados como «Errores comunes y soluciones».
2. **React no se puede seguir tal como está escrito.** El módulo 0 y los módulos 1, 2, 4, 5, 7, 8, 10 y 12 piden «pega el componente en `src/App.jsx`», pero los fragmentos no traen `import` ni `export default` y no instalan sus dependencias. Además, el curso ordena `npm test` 77 veces aunque la plantilla de Vite no trae ese script.
3. **Hay errores técnicos que comprobé ejecutando el código.** El ejemplo de hoisting de JavaScript lanza `ReferenceError` en lugar de imprimir lo que promete. La primera prueba de Vitest del curso falla. La lección afirma que JSX deja de compilar en un caso en que compila. El curso da un mensaje de error de Hooks equivocado y ejecuta una Server Action en Vite, donde el código acaba en el bundle del cliente. La configuración de React Compiler se ignora sin aviso con Vite 8.
4. **JavaScript está mejor que React.** Casi todo su código corre y usa el tuteo de forma consistente. Aun así, tiene huecos de base, datos de edición de ECMAScript equivocados y un proyecto integrador que no se puede ejecutar.
