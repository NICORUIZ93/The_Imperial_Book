CAPÍTULO 2

Ejercicios

Doce ejercicios para hacer en tu computador, de lo mecánico a lo abierto. Las pruebas de cada uno te dicen si está bien; nadie más tiene que corregirte.

Cómo trabajar

Descarga la carpeta cap02-ejercicios. Cada ejercicio tiene un archivo con el esqueleto de la clase y un archivo de pruebas que al principio falla. Tu trabajo es que pase.

$ java -version            # debe decir 21 o superior (Capítulo 0)
$ cd cap02-ejercicios
$ ./gradlew test --tests PuntoTest
  1. Escribe la solución a mano, sin copiar del capítulo.
  2. Ejecuta las pruebas. Si fallan, lee el mensaje completo antes de cambiar nada.
  3. Mira la pista solo después de un intento real. La solución está en el Apéndice B.

A · Mecánicos

Repítelos hasta escribirlos sin mirar. Es la parte de «memoria mecánica»: el objetivo es que el patrón te salga solo.

A1. Escribe a mano equals y hashCode para Punto(int x, int y). PuntoTest · 5 pruebas
A2. Lo mismo para Moneda(String codigo, int decimales). MonedaTest · 6 pruebas
A3. Lo mismo para Rango(LocalDate desde, LocalDate hasta), donde hasta puede ser null. RangoTest · 7 pruebas
A4. Convierte las tres clases en record. Las mismas pruebas deben seguir pasando sin tocarlas.

D · Problemas

Sin esqueleto ni pruebas: tú escribes ambos. Tienen más de una respuesta válida.

D1. Diseña la clave de idempotencia de un pedido: qué campos entran, cómo se normalizan y qué pruebas demuestran que dos envíos repetidos se reconocen.
D2. Una clase no final usa instanceof en equals y una subclase añade un campo. Encuentra el caso que rompe la simetría y escribe la prueba que lo demuestra.

Cuando algo falla

No todos los errores enseñan lo mismo. Antes de buscar la solución, identifica de qué tipo es.

Error del tema

Tu código compila y corre, pero el resultado es otro. Ejemplo: expected: <15> but was: <null>.

Es el que más enseña. Vuelve a la sección del capítulo, no a internet: la respuesta está en el concepto.

Error del entorno

Falla antes de llegar a tu lógica. Ejemplo:

java.lang.UnsupportedClassVersionError: Punto has been compiled by a more
recent version of the Java Runtime (class file version 65.0), this version
of the Java Runtime only recognizes class file versions up to 55.0

Léelo por partes: 65 es Java 21 y 55 es Java 11. Compilaste con uno y ejecutas con otro. El Apéndice A explica cómo leer este y otros 20 errores frecuentes, sin darte el comando hecho.
