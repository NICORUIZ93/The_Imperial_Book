# Versiones de main archivadas en la fusión del 2026-11-12

La rama `avances-7pasos-java-y-plan-20261028` y `main` reescribieron en paralelo
las mismas lecciones (Java M0–M20, Spring Boot M0–M23, Cloud M0, Node M14) y
algunos documentos de metodología. Al fusionarlas se dejó como vigente la versión
de `avances-7pasos` (la más reciente, método de cuatro pasos) y se conservó aquí,
sin cambios, la versión que tenía `main` (corte del 2026-11-03, PR #8), para que
ningún contenido se pierda y pueda reincorporarse tema por tema.

- `web/public/content/...`: lecciones de `main` con la misma ruta que su par vigente.
- `examples/...`: laboratorios de `main` que tenían la misma ruta que los de `avances`.
- `docs/...`: guías de metodología de `main`.

El módulo de Spring Boot «Concurrencia avanzada en Spring» (M23 en `main`) no se
archivó: sigue publicado como `spring-boot/modulo-26.md`.

Estos archivos no forman parte del catálogo de la app ni de las auditorías.
