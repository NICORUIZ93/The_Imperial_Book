# Archivo histórico de documentos de proceso

Notas de sesión, bitácoras de avance y entregas fechadas que ya cumplieron su
función y fueron superadas por documentos activos (p. ej.
`docs/ESTADO-REVISION-MINUCIOSA-20261101.md`, `docs/AUDITORIA-COBERTURA-SPRING-20261101.md`).

Se conservan por trazabilidad histórica; no forman parte del contrato editorial
activo ni los consume la aplicación o `scripts/validate.sh`. No editar: son
instantáneas de su fecha.
