# Plantilla libro (Spec 031)

Plantillas canónicas para cursos escritos como libros técnicos.

- `portada-curso.md`: portada/índice del curso-libro.
- `capitulo.md`: capítulo/lección (15 puntos Spec 028, profundidad libro).
- `lab-README.md`: README de laboratorio reproducible.

Reglas:
- Sin stubs ni `PENDIENTE`.
- Código completo ejecutable en `labs/<id>/`.
- Comandos y salidas reales.
- `verify.sh` verde.
